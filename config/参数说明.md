# 坦克动荡 3 本地版 — 配置说明

## 玩法配置：config.json（推荐，改完刷新即生效）

打开游戏文件夹里的 **`config.json`**（记事本即可编辑），修改后**保存 → 浏览器按 Ctrl+F5 刷新**就生效，
**不需要重启服务器**。

| 配置项 | 说明 | 默认值 |
|---|---|---|
| 子弹速度倍率 | 普通/大/小/直线子弹速度。1.0=原版，0.5=半速，2.0=双倍 | 0.5 |
| 导弹速度倍率 | 追踪导弹、RC 导弹速度 | 0.5 |
| 爆炸碎片速度倍率 | 坦克爆炸碎片的飞散速度 | 1.0 |
| 子弹存留时间倍率 | 所有子弹/导弹在场上存活的时间。1.0=原版（普通子弹10秒、小子弹5秒、导弹15秒等） | 1.0 |

> 技术备注：这个游戏的子弹寿命是"开火时启动一个计时器，每帧检查 计时器时间 ≥ 阈值 就销毁子弹"
> 实现的（阈值：普通子弹10秒、小子弹/大子弹5秒、直线子弹10秒、导弹15秒）。
> 启动器改的就是这个销毁阈值，改完刷新即生效。
| 单人模式道具刷新 | true=单人（人机）模式也刷新道具；false=保持原版（单人无刷新） | true |
| 道具刷新间隔秒 | 每多少秒检查一次是否补道具（所有模式） | 12 |
| 道具场上数量上限 | 场上最多同时存在的道具数 | 3 |

规则：每"道具刷新间隔秒"检查一次，场上道具 ≤ 上限-1 时生成新的。

> 举例：
> - 想恢复原版速度：把两个速度倍率改成 1.0
> - 想要"子弹雨"：存留时间倍率 2.0 + 刷新间隔 5 + 上限 5
> - 想关闭单人道具：单人模式道具刷新 改 false

## 文件说明（目录结构）

```
TankTrouble/
├── config/            ← 配置
│   ├── config.json      ★ 玩家配置文件（改这里，刷新即生效）
│   └── 参数说明.md      本说明文档
├── src/               ← 游戏运行文件
│   ├── index.html        游戏入口页
│   ├── c2runtime.js      游戏引擎
│   ├── data.js           启动器按配置生成的游戏数据（别手动改）
│   ├── data.js.base      纯净原版游戏数据（基准，别动）
│   └── jquery/firebase/pathfind/ga_init/appmanifest/icon...
├── assets/            ← 全部贴图/音效/迷宫数据（100 个文件）
├── 归档/              ← 开发测试工具（见其 README）
├── launcher.py        ← 启动器：读配置 → 生成数据 → 起服务器 → 开浏览器
└── 启动游戏.bat       ← 双击启动（自动找空闲端口 + 自动搜 Python）
```

技术说明：启动器生成 data.js 时会把资源路径自动改写为 `../assets/…`
（引擎按相对页面路径加载），所以贴图可以安全地全部放在 assets/。

## 启动方式

双击 `启动游戏.bat`。服务器窗口会打印当前生效的配置；关掉窗口即停止。

启动脚本会自动在本机搜索 Python 3（顺序：`py` 启动器 → `python` → `python3` →
常见安装目录 LocalAppData / Program Files / Program Files (x86) / C:\Python*），
找到后校验版本再运行；**如果本机没装 Python 3，会明确报错并提示安装**（不会静默失败）。

## 归档文件夹

`归档/` 里存放了开发测试工具（冒烟启动测试、配置生效验证脚本），与游戏运行无关，
用途和用法见 `归档/README.md`。

## 常见问题

- 改了配置没反应？→ 确认保存了 config/config.json，并在浏览器按 **Ctrl+F5**（强制刷新，绕过缓存）
- 配置写坏了？→ 删掉 config/config.json 再刷新，会按默认值运行
- 想完全还原原版？→ 把所有倍率改回 1.0、单人刷新改 false（`src/data.js.base` 是永远不变的纯净基准）
