# src/ai 黑箱使用说明

`src/ai/` 是你和游戏之间的"中间层"，**可以完全当黑箱用**：你只需要往 Python 端写决策逻辑
（`python/bot.py`），不需要理解游戏内部任何东西。

## 一、src/ai 里有什么

| 文件 | 角色 | 你需要碰吗 |
|---|---|---|
| `ai-bridge.js` | 游戏端桥：采集状态 → WebSocket 发给 Python；接收动作 → 合成键盘/鼠标输入 | ❌ 黑箱 |
| `evaluate.js` | 无头评估器：8 倍速自动对战 + 输出指标 | ✅ 用命令行调用 |

## 二、黑箱的输入输出契约

### 状态（游戏 → Python，约 30Hz，JSON）

```json
{
  "t": 123.45,                  // 游戏时间（秒）
  "layout": "1 Player",
  "me":  { "x": 482.5, "y": 202, "angle": 1.95, "aim": 2.1, "vx": 0, "vy": 0 },
  "foe": { "x": 520.2, "y": 261, "angle": 0.05, "aim": 0.05, "vx": 1, "vy": -2 },
  "bullets": [ { "x": 100, "y": 200, "vx": 50, "vy": 0, "type": 44 }, ... ],
  "powerups": [ { "x": 300, "y": 400 }, ... ],
  "map": { "w": 30, "h": 20, "tileW": 57, "tileH": 57,
           "x": 197.5, "y": 31, "ox": 0, "oy": 0,
           "grid": [ [0,2,2,...], ... ] }     // 只在进入新对局时发送
}
```

字段含义：
- `me`/`foe`：我方（绿）/敌方（红）坦克，`x/y` 世界坐标，`angle` 车身朝向（弧度，0=右，顺时针），
  `aim` 炮塔朝向，`vx/vy` 速度（像素/秒，由桥差分计算）
- `bullets`：所有弹丸（含导弹）的位置与速度
- `map`：迷宫网格，见 `config/地图机制.md`

### 动作（Python → 游戏，JSON）

```json
{ "keys": { "up": 1, "down": 0, "left": 0, "right": 1 },
  "fire": 1, "mx": 300, "my": 400 }
```

- `keys`：四个方向键，0/1
- `fire`：开火，0/1
- `mx/my`：鼠标位置（决定炮塔瞄准方向 + 开火落点）

### 控制协议（Python 端要实现的入口）

```python
# python/bot.py
class Bot:
    def decide(self, state: dict) -> dict:
        # state = 上面的状态 JSON
        # 返回动作 JSON
        return {"keys": {"up": 1, "down": 0, "left": 0, "right": 0},
                "fire": 0, "mx": state["me"]["x"], "my": state["me"]["y"]}
```

你只需要维护 `decide()` 这一个函数——**它就是整个 AI 的入口**。

## 三、怎么运行

```bat
启动游戏.bat                          ← 游戏 + AI 桥一起启动
                                     （浏览器里你的 bot 自动接管玩家坦克）
```

无头自动评估（8 倍速，测撞墙/贴墙/交战）：

```bat
node src/ai/evaluate.js --port 8765 --matches 3
```

输出指标：

| 指标 | 含义 | 说明 |
|---|---|---|
| 实际时长 | 对局持续的游戏秒 | 直到回到菜单或 240s 上限 |
| 撞墙 我/敌 | 撞击次数 | 进入墙体算 1 次；持续贴墙每 1 秒再 +1 |
| 贴墙秒 我/敌 | 贴墙总时长 | 数值越大 = 越不会避障 |
| 同屏最多弹丸 | 交战激烈程度 | 我方开火是否生效的探针 |

> 击杀统计：无头环境的碰撞链不可用，**已放弃**。需要击杀指标请在真实浏览器里观察
> （游戏右上角计分板），或在桥接状态里自行扩展。

## 四、常见问题

- **Q：改 ai-bridge.js 会影响什么？**
  影响所有使用桥的环节（真机 + 无头）。除非你要扩展状态字段，否则不要动。
- **Q：无头评估和真机行为一致吗？**
  导航/撞墙类指标一致（同一套状态+动作链路）；击杀类在无头不可用（见上）。
- **Q：我可以加状态字段吗？**
  可以：在 ai-bridge.js 的 `collect()` 里加字段（如道具类型），Python 端直接收到。
- **Q：bot 决策频率是多少？**
  状态 ~30Hz，动作随状态帧返回；决策代码保持轻量（<5ms）即可。
